# diabetes-prediction-django
🩺 MediPredict – Diabetes Risk Prediction Platform

MediPredict is a web-based medical decision support system that predicts the risk of diabetes using machine learning models trained on the Pima Indians Diabetes Dataset.

The application allows healthcare professionals to:

manage patient records

run diabetes risk predictions

store prediction history

analyze patient data through a dashboard

The system integrates Machine Learning models with a Django web application to create a complete predictive analytics platform.

🚀 Features
👤 Authentication System

Doctors can securely log in to access their patient records.

🧑‍⚕️ Patient Management

Doctors can:

create new patients

view patient details

manage patient records

🤖 Machine Learning Predictions

The application uses multiple trained ML models:

Logistic Regression

Random Forest

Neural Network (MLP)

These models predict whether a patient is Diabetic or Healthy based on medical features.

📊 Dashboard Analytics

The dashboard provides:

total patients

total tests performed

diabetic vs healthy distribution

average patient age

recent diagnostic results

📜 Prediction History

All predictions are stored in the database and linked to specific patients.

This allows doctors to review past diagnostic results.

🧠 Machine Learning Models

The models were trained using the Pima Indians Diabetes Dataset.

Input features include:

Pregnancies

Glucose

Blood Pressure

Skin Thickness

Insulin

BMI

Diabetes Pedigree Function

Age

Additional engineered features were also used:

Glucose × BMI

Glucose × Age

BMI × Age

Pregnancies × Age

Insulin × Glucose

DPF × Age

The trained models are stored as serialized files:

predictor/ml_model/
├── LR.joblib
├── RF.joblib
└── NN.joblib

⚙️ Installation
1️⃣ Clone the repository
git clone https://github.com/your-repo/mediPredict.git
cd mediPredict
2️⃣ Create virtual environment
python -m venv venv

Activate:

Windows

venv\Scripts\activate

Linux / Mac

source venv/bin/activate
3️⃣ Install dependencies
pip install -r requirements.txt
4️⃣ Run migrations
python manage.py makemigrations
python manage.py migrate
5️⃣ Create admin user
python manage.py createsuperuser
6️⃣ Run the server
python manage.py runserver

Open in browser:

http://127.0.0.1:8000
🔐 Login

Use the credentials created with:

python manage.py createsuperuser
🗄️ Database

The project currently uses:

SQLite

db.sqlite3

All patients and predictions are stored locally.

For production, a server-based database such as PostgreSQL is recommended.

📊 Workflow

Doctor logs into the system

Doctor creates a new patient

Doctor enters medical data

Machine learning models generate predictions

Results are stored in the database

The patient's diagnostic history is updated

Analytics are displayed in the dashboard
