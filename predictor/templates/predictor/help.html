USER GUIDE

How to Use MediPredict

This page explains how doctors can use the platform to manage patients, run diabetes risk predictions, and review previous diagnostic records.

Step-by-Step Instructions

1

Log in

Access the application using your doctor account credentials. After login, you will be redirected to the main dashboard.

2

Add a New Patient

Go to the Patients section and click Add New Patient. Fill in the patient's basic information such as first name, last name, age, and gender.

3

Open the Patient File

After creating the patient, open the patient file to access the diagnostic form and view previous prediction history.

4

Enter Medical Data

Fill in the medical indicators required by the machine learning model, including pregnancies, glucose, blood pressure, skin thickness, insulin, BMI, diabetes pedigree function, and age.

5

Run the Prediction

Click Run Prediction to analyze the patient data. The system uses trained machine learning models to estimate diabetes risk.

6

Review the Result

The prediction result will be stored in the patient's history. You can review previous diagnostic entries at any time.

7

Use the Dashboard

The dashboard provides an overview of your patients, total tests, and risk distribution. It helps monitor the recorded diagnostic activity.

Important Notes

  • Each doctor can only access their own patients and records.
  • Predictions are stored automatically after each diagnostic submission.
  • This system is intended for educational purposes and preliminary assessment only.
  • The generated result does not replace professional medical diagnosis.

Best Practice

To maintain clear medical records, doctors should create a patient profile first, then run predictions only from the patient's dedicated file so that all results are correctly linked to the right history.
